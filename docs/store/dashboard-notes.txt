Single purpose
Search or discuss selected webpage text using the configured search engine or AI website with a middle-click, or open selected web addresses, with configurable tab focus and site controls.

Permission explanations
storage: Save and sync search engine, tab behavior, and site preferences. Keep short error diagnostics in browser session storage.
activeTab: When the user opens the toolbar popup, identify the current page to show page readiness and let them enable or disable the extension for that site.
offscreen: Create a hidden extension document for clipboard writes when the user enables copy-on-search. Manifest V3 service workers cannot access the DOM needed for copying.
clipboardWrite: Copy the selected text only when copy-on-search is enabled and the user performs a search gesture. The extension does not read the clipboard.
Webpage access through content-script match patterns: Detect the user's middle-click and read their selection on HTTP(S) pages, including frames. Site controls determine where gestures are enabled. No browsing history is collected.

Remote code
No remote code is executed. All JavaScript is bundled in the extension. Search destinations are URLs opened in new tabs, not downloaded code.

Data practices
The extension does not collect data for the developer, sell user data, run analytics, or use advertising. Preferences sync through Chrome's own storage service. A user-triggered gesture sends selected text to the configured search or AI website in a navigation URL. AI destinations also receive the configured prompt and optional source page URL; page URL inclusion can be turned off. Gemini draft filling and ChatGPT/Gemini auto-send only operate in extension-authorized tabs. Auto-send is experimental and off by default. Short-lived prompt fingerprints and tab authorization metadata are kept in session storage, without storing prompt text there. Opt-in copying writes selected text to the user's clipboard. Short failure diagnostics remain in session storage and are cleared on navigation, dismissal, or successful retry. The developer receives no selections or search history.

Reviewer test instructions
Use an ordinary HTTP(S) webpage. Select text and press the mouse wheel; a search tab should open beside the source tab. Ctrl/Command reverses tab focus. Open the toolbar popup for quick controls, then Settings. Select a link-focus mode, save changes, and middle-click a normal HTTP(S) link. Optionally enable copy-on-search, save, search selected text, and paste to verify the clipboard. Disable the current site in the popup to leave its gestures to the browser. Basic search needs no account. AI websites may require an account. For AI testing, choose ChatGPT, Gemini, Claude, Perplexity, or Custom AI under Search engine / AI; save and middle-click a selection. The AI prompt uses {text} and optional {url}. Custom AI URL templates use %s for the full prompt. Claude requires manual sending; Perplexity submits via its URL. Optional ChatGPT/Gemini auto-send is labeled experimental. Refresh existing webpages after installing the extension. Browser-protected pages cannot run the content script.
